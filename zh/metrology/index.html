附带不确定度的显微图像分析。

上传电子显微镜或光学显微镜图像，即可获得可存档的测量结果：带置信区间的统计、自动质量检查、对照图和 PDF 报告。每个工具按需运行、按图像计费，并提供基于真值已知的合成图像的免费演示。

SEM / TEM · 粉体与纳米颗粒
粒径分析与欧盟纳米材料筛查
带 95% 置信区间的 D10/D50/D90、Feret 直径，以及 100 nm 及以下颗粒的比例和“符合／不符合／临界”结论。
金相 · 增材制造、铸件、涂层

纤维直径
按 CD-SEM 线宽方式测量的长度加权直径分布，附 95% 置信区间，并评估珠粒和纤维取向。

SEM 比例尺与像素尺寸检查（英文）
从 Zeiss 和 Thermo Fisher 的 TIFF 元数据读取像素尺寸，测量比例尺并交叉核对。图像不会离开您的电脑。

这些工具有何不同

  • 不确定度优先。每个主要数字都附有置信区间；当结果过于接近阈值而无法下结论时，工具会明确说明。
  • 看得见的检查。每次运行都会就比例尺一致性、样本量、对比度等给出绿、黄、红评级，并在对照图上勾勒出每个检测到的对象。
  • 可追溯。报告记录引擎版本、参数和图像的 SHA-256 指纹：同样的图像总是得到同样的数字。
  • 无需安装，无需许可证。在 Apify 上按图像付费，或通过 Apify API 和 MCP 服务器从脚本和 AI 智能体调用。
