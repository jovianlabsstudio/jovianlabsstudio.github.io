# Jovian Labs

Source of [jovianlabsstudio.github.io](https://jovianlabsstudio.github.io): small data tools that update themselves.

- `tenders/`: failed and relaunched public tenders in Europe, rebuilt every Monday by `.github/workflows/tenders.yml` from the TED and BOAMP open data.
- `ai-index/`: AI Recommendation Index, rebuilt every Monday by `.github/workflows/ai-index.yml` once the API keys are set as repository secrets.
