不確かさまで示す、顕微鏡画像解析。

電子顕微鏡や光学顕微鏡の画像をアップロードするだけで、記録に残せる計測結果が得られます。信頼区間つきの統計、自動品質チェック、確認画像、PDF レポート。各ツールは必要なときに実行でき、1 画像ごとの課金で、真値が既知の合成画像による無料デモを用意しています。

SEM / TEM · 粉体・ナノ粒子
粒子径解析と EU ナノ材料スクリーニング
95% 信頼区間つきの D10/D50/D90、フェレ径、100 nm 以下の粒子の割合と「該当／非該当／境界」の判定。
金属組織 · 積層造形・鋳物・コーティング
研磨断面のポロシティ
95% 信頼区間と相対精度つきの面積ポロシティ、気孔サイズ、最大気孔、球状気孔と融合不良気孔の分類。
SEM · エレクトロスピニング・フィルター
繊維径
CD-SEM の線幅計測と同じ考え方で測った、95% 信頼区間つきの長さ加重径分布。ビーズと配向も評価。
無料ツール · ブラウザ内で動作
SEM スケール・ピクセルサイズ確認（英語）
Zeiss と Thermo Fisher の TIFF メタデータからピクセルサイズを読み取り、スケールバーを計測して照合。画像は PC の外に出ません。

他のツールとの違い

  • 不確かさを第一に。主要な数値にはすべて信頼区間を付け、しきい値に近すぎて結論できない場合はそう明示します。
  • 目に見えるチェック。スケールの整合性、サンプル数、コントラストなどを各実行で緑・黄・赤で自己評価し、検出したすべての対象を確認画像に描画します。
  • トレーサビリティ。レポートにはエンジンのバージョン、パラメータ、画像の SHA-256 指紋を記載。同じ画像からは常に同じ数値が得られます。
  • インストール不要、ライセンス不要。Apify で 1 画像ごとに支払うか、Apify API や MCP サーバー経由でスクリプトや AI エージェントから呼び出せます。
