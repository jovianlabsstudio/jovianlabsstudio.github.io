Free: check the scale of a whole folder

Before measuring, check the calibration: the SEM scale bar & pixel-size check reads the pixel size from Zeiss and Thermo Fisher TIFF metadata, measures the scale bar, cross-checks them, flags mixed magnifications and exports images with a clean scale bar. It runs in your browser: images never leave your computer.

Run it on your images

  1. Open a tool on Apify and press Start with an empty image list: the free demo shows the full report on synthetic images.
  2. Paste direct links to your images (TIFF, PNG or JPG; several fields of view of one sample) and the scale bar length.
  3. Get the PDF report, the control image, a CSV of every object and a JSON summary. The same tools are callable from Python, from a scheduler and from AI agents through the Apify API and MCP server.
