How these tools differ

  • Uncertainty first. Every headline number comes with its confidence interval, and the tools say when a result is too close to a threshold to conclude.
  • Checks you can see. Each run rates itself green, amber or red on scale consistency, sample size, contrast and more, and outlines every detected object on a control image.
  • Traceable. The report carries the engine version, parameters and SHA-256 fingerprints of the images: the same images always give the same numbers.
  • No installation, no licence. Pay per image on Apify, or call the tools from scripts and AI agents through the Apify API and MCP server.
